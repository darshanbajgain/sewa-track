# Seed data

## `locations.json`

Provinces (7), districts (77) and local levels (753) of Nepal, with English and Nepali names,
local level type and number of wards (6,743 in total).

- **Source:** [sagautam5/local-states-nepal](https://github.com/sagautam5/local-states-nepal),
  commit `035cb3d2ce2420ad04d7aac1d0ce4d08960c57f0`
- **Generated by:** `apps/api/src/db/import-locations.ts` (`pnpm --filter @sewa/api import:locations`)
- **Changes from the source:** kept only ids, names, type and ward count; removed website links,
  area and headquarters; fixed one Nepali spelling (`काेशी` → `कोशी`, two vowel signs → one).
- **Checked against official figures:** 7 / 77 / 753; 6 metropolitan, 11 sub-metropolitan,
  276 municipalities, 460 rural municipalities; 6,743 wards.
- **Coordinates:** not included. Local level centroids will be added from a verified boundary
  file that follows Nepal's official 2020 map.
