# Seed data

## `locations.json`

Provinces (7), districts (77) and local levels (753) of Nepal, with English and Nepali names,
local level type and number of wards (6,743 in total).

- **Source:** [sagautam5/local-states-nepal](https://github.com/sagautam5/local-states-nepal),
  commit `035cb3d2ce2420ad04d7aac1d0ce4d08960c57f0`
- **Generated by:** `apps/api/src/db/import-locations.ts` (`pnpm --filter @sewa/api import:locations`)
- **Changes from the source:** kept only ids, names, type and ward count; removed website links,
  area and headquarters; fixed one Nepali spelling (`काेशी` → `कोशी`, two vowel signs → one).
- **Checked against official figures:** 7 / 77 / 753; 6 metropolitan, 11 sub-metropolitan,
  276 municipalities, 460 rural municipalities; 6,743 wards.
- **Coordinates:** not included (the map works on district shapes, see below).

## District boundaries

`apps/web/public/geo/nepal-districts.geojson`: the 77 district shapes for the delay map.

- **Source:** [Acesmndr/nepal-geojson](https://github.com/Acesmndr/nepal-geojson), commit
  `0e084221686fba8a4a8c1590661367676e96e473`, file `generated-geojson/nepal-with-districts-acesmndr.geojson`
  ("lightweight", simplified; not survey-grade). MIT License, Copyright (c) 2018 Aashish Manandhar.
- **Generated by:** `apps/api/src/db/import-district-map.ts` (`pnpm --filter @sewa/api import:district-map`)
- **Changes from the source:** each shape gets our `districtId` (8 spellings mapped, e.g. Tehrathum →
  Terhathum); names/HQ/province dropped; coordinates rounded to 4 decimals (~11 m). 1.0 MB, 0.26 MB gzipped.
- **Official 2020 map check (AGENTS §3.6):** Gunji (30.187 N, 80.863 E), Kuti (30.322 N, 80.763 E) and
  Kalapani (30.208 N, 80.990 E), all in the area added by the 2020 map, fall inside Darchula. The same test
  rejected `mesaugat/geoJSON-Nepal` (old map); `manishacharya60/nepal-geojson` passed but has no license.
